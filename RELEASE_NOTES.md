# Journal Pre-proof repository package

This public package corresponds to the article accepted by *Journal of Pathology Informatics* on 8 September 2026, DOI [10.1016/j.jpi.2026.100720](https://doi.org/10.1016/j.jpi.2026.100720).

It contains the supplied Journal Pre-proof PDF, the eight files present in the supplied ScienceDirect supplementary archive (Tables S1–S7 and Supplementary Search Strategies), and the final-submission Supplementary Figure S1 TIFF. The ScienceDirect archive itself did not include Figure S1.

The PDF is a pre-proof and may differ from the definitive Version of Record. Consult the DOI for the current journal version.
