# Entity-aware pathology workflow informatics

This repository contains the article and the supplementary files supplied for:

> Li A, O'Loughlin P, Yue L, Zhang WE, Swart B, Chen W. **Entity-aware pathology workflow informatics: Structured evidence mapping and a reference architecture for governed orchestration.** *Journal of Pathology Informatics* (2026). [doi:10.1016/j.jpi.2026.100720](https://doi.org/10.1016/j.jpi.2026.100720).

The article was accepted on 8 September 2026. The PDF here is the publisher's **Journal Pre-proof**, not the definitive Version of Record; use the DOI for the current journal version. The repository address is the one printed in the article: https://github.com/AoXan/pathology-workflow-informatics-systematic-mapping. The PDF's statement that the repository was private refers to the earlier double-anonymized review period; this repository is public after acceptance.

## Files

- [`paper/JPI_2026_100720_Journal_Preproof.pdf`](paper/JPI_2026_100720_Journal_Preproof.pdf): the supplied 35-page Journal Pre-proof, unchanged. Figures 1–4 and the article tables are in this PDF.
- [`supplement/Supplementary_Table_S1.xlsx`](supplement/Supplementary_Table_S1.xlsx): the 98-record evidence base (74 primary and 24 supplementary records).
- [`supplement/Supplementary_Table_S2.xlsx`](supplement/Supplementary_Table_S2.xlsx): 124 full-text exclusions and reasons.
- [`supplement/Supplementary_Table_S3.xlsx`](supplement/Supplementary_Table_S3.xlsx): evidence-to-requirement traceability.
- [`supplement/Supplementary_Table_S4.xlsx`](supplement/Supplementary_Table_S4.xlsx): display denominator guide, including Figure 2 (97 classifiable records) and Figure 3 (93 classifiable records).
- [`supplement/Supplementary_Table_S5.xlsx`](supplement/Supplementary_Table_S5.xlsx): background methodological literature and standards.
- [`supplement/Supplementary_Table_S6.xlsx`](supplement/Supplementary_Table_S6.xlsx): D1–D4 coding definitions and rules.
- [`supplement/Supplementary_Table_S7.xlsx`](supplement/Supplementary_Table_S7.xlsx): historical 30-record assessment and the blinded 50-record reviewer-verification exercise.
- [`supplement/Supplementary_Figure_S1.tiff`](supplement/Supplementary_Figure_S1.tiff): workflow for deriving architecture requirements from the structured evidence map.
- [`supplement/Supplementary_Search_Strategies.docx`](supplement/Supplementary_Search_Strategies.docx): retained search information and labelled rerun translations.

The seven workbooks and search-strategy document are byte-for-byte copies of the files distributed in the supplied ScienceDirect archive (`mmc1`–`mmc7` and `mmc9` respectively); only their filenames were made descriptive. The archive did not include `mmc8`. Supplementary Figure S1 is a byte-for-byte copy of the TIFF in the final JPI revision submission package, not an earlier repository figure.

The article is a structured evidence map and reference-architecture proposal. It does not report an implemented or clinically validated orchestration platform. No patient-level data are included.
